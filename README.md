# Trilha da Inclusão

Projeto inspirado na maquete enviada: uma trilha acessível com desafios para pessoas surdas e cegas.

## Como funciona

### Percurso para pessoa surda
- Existem **11 bandeirinhas vermelhas**.
- Em cada bandeirinha é sorteada uma carta.
- A carta apresenta uma palavra.
- O participante deve fazer o sinal correspondente em **Libras**.
- Depois, confirma o desafio e avança para a próxima bandeirinha.

### Percurso para pessoa cega
- A trilha possui **11 pontos de desafio**.
- Em determinados pontos ocorre uma mudança de textura.
- A textura funciona como pista para o participante descobrir o caminho correto.
- O percurso possui **3 recompensas** espalhadas pelo caminho.
- O objetivo é chegar ao final conquistando as três recompensas.
- O jogo também possui narração por voz do navegador e pode ser controlado pelas setas do teclado.

## Objetivo

Promover uma atividade inclusiva, na qual os participantes precisam perceber pistas diferentes de acordo com o percurso escolhido.

## Arquivos

- `index.html` — estrutura da atividade.
- `style.css` — aparência e acessibilidade visual.
- `game.js` — regras, cartas, texturas, recompensas e controles.
